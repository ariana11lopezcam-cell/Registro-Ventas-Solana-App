# Programa `registro`

`src/lib.rs` es el programa base de WayLearn más la mejora **cajeros autorizados** (bloques marcados como "MEJORA"). Las instrucciones y cuentas base no cambian.

Pégalo en un proyecto Anchor de Solana Playground, compila y despliega en Devnet. `declare_id!("")` se llena al compilar.

`client/client.ts` es el cliente de referencia original del bootcamp (solo el flujo base).
